### Does remote start work on a push-button car from Walnut?

Most push-button vehicles are supported with the right Compustar bypass, and the key stays in your pocket as before. A few models need a specific module or are not supported at all, so send the year, make and model by text and we will confirm before you commit to the drive.

### What happens if someone tries to drive off a remote-started car?

Nothing. The vehicle is running but the transmission will not shift without the key present, and opening a door or touching the brake shuts the engine down. Remote start installation adds convenience without opening a new way into the car.

### How long does a remote start installation take?

Plan on a good part of the day for remote start, and longer if an alarm is going in at the same time. For a drive from Walnut, we suggest an early slot so the car is ready by mid-afternoon, or a drop-off with pickup the next morning.

### Can you install remote start on a car that already has an aftermarket alarm?

Usually, but we check the existing system first. Many alarms arrive with wiring nobody has verified, and remote start depends on clean ignition and door circuits. If the old install is sound we build on it; if not we tell you what we found and what it would take to fix.
