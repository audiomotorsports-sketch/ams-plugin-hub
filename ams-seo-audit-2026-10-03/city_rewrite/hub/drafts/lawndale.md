## Alarm and remote start questions from Lawndale

### Why would a Lawndale driver come to Carson for a car alarm?

Because the install quality is what makes an alarm useful. We hide the module, solder the connections and set the shock sensor so it does not false-trigger on a passing truck. The drive from Lawndale is about 6.5 miles, and the car is usually finished the same day you drop it.

### Does remote start installation work on a push-button start car?

Yes, the Compustar 9910 supports most push-button vehicles with the correct bypass module. The car starts from the fob, runs for a set time and shuts off if nobody gets in. Give us your year, make and model and we will confirm fit before booking.

### Can an alarm and remote start share one remote?

They can. When we install a Compustar remote start with the alarm option, one two-way fob handles lock, unlock, start and alerts. Many Lawndale customers add it on later, so if you only want the alarm today, we wire it so remote start can be added.

### Will adding GPS tracking drain my battery?

No, a properly installed tracker draws very little current and sleeps when the car is parked. We wire it to constant power and ignition so it knows when the vehicle moves. It is a good fit for a car that is financed, shared with a teen driver or parked on the street.

### Do you tint windows while the alarm is being installed?

Yes, and it is an efficient way to use the visit. Tint and alarm work happen in the same bay, so a Lawndale customer can book both and pick up one finished car. Mention both services when you call so we schedule enough time.
