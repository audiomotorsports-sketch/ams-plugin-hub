## Fullerton alarm and remote start questions

### Is it worth driving from Fullerton for remote start installation?

Yes. Remote start depends on the bypass module being programmed correctly and the wiring being soldered into the right circuits; done right, it works every morning for years. The drive is about 19.7 miles, and you can wait at the shop or drop the car for the day.

### Can I control the remote start from my phone instead of a fob?

Yes. The Compustar 9910 can be paired with a phone control option so you can start, lock and unlock from an app, with range limited only by cell coverage. Many customers keep the fob for daily use and add phone control for when the car is parked far away.

### What does Viper alarm installation include?

The Viper 3108V install includes a shock sensor, siren, starter interrupt and a two-way remote, with the module hidden and the connections soldered rather than clipped. We adjust the sensor so it does not false-trigger on a passing truck but still reacts to a hit on the glass.

### Can an alarm and remote start be installed together for a Fullerton commuter?

Yes, and it is the most common package we do. Viper alarm installation and Compustar remote start installation share one two-way fob, so you lock, unlock, arm and start from a single remote. Both are done in the same appointment, usually within the day.

### Do you tint windows while the alarm is installed?

Yes. Window tint and alarm work run in the same bay at the same time, so a Fullerton driver can book both and pick up one finished car. Solar or Solar Ceramic film goes on the doors and rear glass. Mention both jobs when you schedule.
