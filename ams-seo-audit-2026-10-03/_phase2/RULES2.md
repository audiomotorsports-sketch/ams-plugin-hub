# Phase 2 (launch audit) rules for every agent
- READ-ONLY. No commit/push/deploy/delete/modify of any site or repo. NEVER submit a form, never click a purchase/book/send button that posts data, never create accounts or carts with real orders. Inspect forms (fields, labels, required, action URL, honeypot/captcha, success-state markup if visible) only.
- Write only inside ~/ams-seo-audit-2026-10-03/<site>/launch/ (create it). Use a private scratch dir (mktemp -d) for temp files.
- Harness: `python3 ~/ams-seo-audit-2026-10-03/_phase2/probe.py OUTDIR URL [URL...]` (Playwright, TLS verification ON, phone 390x844 + desktop 1366x900; writes screenshots + probe.json). Read the docstring. Run it in batches of <=8 URLs. View key screenshots with the Read tool (images) and judge layout: overlap, clipped text, unreadable contrast, hero/CTA above the fold on phone, sticky banners covering content, horizontal scroll, tiny tap targets, broken images, layout shift.
- Environment artifacts (NOT site bugs): HTTP 403 / tunnel failure on youtube.com, maps.google.com, other hosts the proxy blocks, and on www.lacarbeats.com / www.lacartint.com / www.lacaralarm.com / www.amspods.com / shop.* of those. Mention them only as 'unverifiable from here'. Transient 502/reset: retry up to 3 times before calling it a site problem.
- Blocked brand domains: audit the hub-mounted copy under https://www.audiomotorsports.com/<mount>/ and label findings [mount-proxy].
- Output: LAUNCH_NOTES.md in the launch folder with sections (a) visual phone+desktop (b) click-through: every nav/footer/CTA/button link status, forms inspected, redirects, 404s (c) bugs: console errors, page errors, mixed content, failed requests, meta/OG/viewport/canonical, favicon/apple-touch-icon, visible stray text/bugs (d) speed/CWV lab numbers per page (LCP/CLS/TBT-proxy/TTFB/transfer) with note that lab != field. Classify each issue MUST-FIX (blocks launch: broken page/link/CTA/form, console error that breaks function, mixed content, noindex/robots that blocks launch, missing viewport, horizontal scroll on phone, LCP>4s, CLS>0.25, visible bugs/leaked text) or NICE-TO-HAVE. Each issue: where (URL), what, evidence, MUST/NICE, exact next step. NEVER suggest removing/merging/noindexing a page or site.
- Sample: home + all primary nav destinations + 2 service pages + 3 city pages (incl. Carson/West Carson and one far-out city) + FAQ/contact/book/reviews/blog index + 1 blog post + 2 product pages if a shop. 15-25 URLs per site; run link-status on all nav/footer/CTA links found.
- End with a 10-line summary of MUST-FIX items.
